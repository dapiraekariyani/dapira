01 — overview

Tujuan Praktikum

Praktikum ini bertujuan memahami proses pembuatan kabel LAN crossover dan penerapannya untuk komunikasi antar komputer.

🔌

Membuat Kabel LAN

Mempelajari proses penyusunan kabel UTP menggunakan konektor RJ45.

🛠️

Crimping

Menggunakan tang crimping untuk mengunci kabel pada konektor RJ45.

🔍

Testing

Memastikan susunan kabel berhasil menggunakan LAN tester.

💻

File Sharing

Menghubungkan dua laptop dan melakukan transfer file melalui LAN.

02 — equipment

alat dan bahan

Siapkan seluruh alat dan bahan berikut sebelum memulai proses perakitan.

🔗

Kabel UTP

Kabel twisted pair yang digunakan sebagai media transmisi data.

🔌

RJ45

Konektor yang dipasang pada ujung kabel UTP untuk koneksi Ethernet.

✂️

Tang Crimping

Digunakan untuk memotong, mengupas, dan melakukan crimping RJ45.

💡

LAN Tester

Digunakan untuk mengecek apakah susunan kabel LAN sudah benar.

03 — wiring standard

04 — practical

cara merangkai kabel crossover

Ikuti langkah berikut secara berurutan agar kabel dapat digunakan dengan baik.

01

Potong kabel UTP

Tentukan panjang kabel yang dibutuhkan kemudian potong kabel UTP menggunakan bagian pemotong pada tang crimping.

02

Kupas bagian luar kabel

Kupas jaket luar kabel dengan hati-hati hingga kabel-kabel kecil di dalamnya terlihat.

03

Susun kabel

Ujung pertama menggunakan T568A dan ujung kedua menggunakan T568B. Pastikan urutan warna sesuai tabel.

04

Luruskan kabel

Luruskan delapan inti kabel dan ratakan ujungnya agar seluruh kabel dapat masuk ke konektor RJ45.

05

Masukkan ke RJ45

Masukkan kabel ke konektor RJ45 sampai semua inti kabel mencapai bagian depan konektor.

06

Lakukan crimping

Masukkan RJ45 ke tang crimping lalu tekan dengan kuat sampai pin konektor mengunci kabel.

07

Ulangi pada ujung lainnya

Gunakan susunan T568B pada ujung kedua sehingga terbentuk kabel LAN tipe crossover.

08

Test menggunakan LAN tester

Hubungkan kedua ujung kabel ke LAN tester dan perhatikan indikator lampu untuk memastikan koneksi setiap pin.

05 — testing

pengujian dengan LAN tester

Setelah crimping selesai, lakukan pengujian sebelum kabel digunakan.

💡 urutan indikator

Pada kabel yang tersusun dengan benar, lampu indikator LAN tester akan menyala sesuai urutan koneksi pin.

1 → 2 → 3 → 4 → 5 → 6 → 7 → 8

jika terdapat lampu yang tidak menyala atau urutannya tidak sesuai, periksa kembali susunan warna, posisi kabel, dan hasil crimping.

06 — network connection

menghubungkan 2 laptop

Hubungkan dua laptop secara langsung menggunakan kabel LAN crossover.

💻

Laptop 1

IP: 192.168.1.1
Mask: 255.255.255.0
💻

Laptop 2

IP: 192.168.1.2
Mask: 255.255.255.0
07 — configuration

setting IP address

Kedua laptop harus berada pada jaringan yang sama.

01

Buka pengaturan Ethernet

Control Panel → Network and Internet → Network and Sharing Center → Change adapter settings.

02

Buka Properties

Klik kanan Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4).

03

Masukkan IP Laptop 1

IP Address : 192.168.1.1
Subnet Mask: 255.255.255.0
Default Gateway: kosong
DNS: kosong
04

Masukkan IP Laptop 2

IP Address : 192.168.1.2
Subnet Mask: 255.255.255.0
Default Gateway: kosong
DNS: kosong
05

Uji koneksi menggunakan Ping

ping 192.168.1.2

Jalankan perintah tersebut pada Laptop 1 melalui Command Prompt. Jika muncul Reply, berarti kedua laptop berhasil berkomunikasi.

08 — file sharing

sharing file melalui kabel LAN

Setelah koneksi berhasil, file dapat dibagikan melalui jaringan lokal.

01

Pilih folder

Pada laptop yang memiliki file, pilih folder yang ingin dibagikan.

02

Aktifkan file sharing

Klik kanan folder → Properties → Sharing → Advanced Sharing → centang Share this folder.

03

Akses dari laptop kedua

\\192.168.1.1

Masukkan alamat tersebut pada File Explorer Laptop 2 untuk mengakses folder yang telah dibagikan.

04

Transfer file

Setelah folder dapat diakses, file dapat disalin atau dipindahkan melalui jaringan LAN.

11 — conclusion

kesimpulan

Pembuatan kabel LAN crossover membutuhkan ketelitian dalam menyusun warna kabel sesuai standar T568A dan T568B. Setelah proses crimping selesai, kabel perlu diuji menggunakan LAN tester untuk memastikan setiap pin terhubung dengan benar. Kabel tersebut kemudian dapat digunakan untuk menghubungkan dua laptop secara langsung dengan konfigurasi IP yang berada dalam satu jaringan sehingga proses sharing file dapat dilakukan.
